# LockIn Clock

LockIn Clock is a modern mood-based motivational flip clock web application built for students, developers, and productivity users. It combines a fullscreen retro flip clock with motivational quotes, Pomodoro focus sessions, daily streaks, and distraction-free Lock-in Mode.

## Features

- Real-time fullscreen flip clock
- Smooth flip animation
- 12-hour and 24-hour time format toggle
- Mood-based motivational quote system
- 50+ quotes per category
- Dynamic mood themes and gradients
- Pomodoro timer with Focus, Short Break, and Long Break modes
- Focus session tracking
- Daily streak system
- Favorite quotes
- Custom user quotes
- localStorage persistence
- Lock-in Mode for distraction-free studying
- Keyboard shortcuts
- Responsive dark glassmorphism UI

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- localStorage
