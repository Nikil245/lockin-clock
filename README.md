# LockIn Clock

LockIn Clock is a modern motivational flip clock web app designed for students, developers, and productivity users. It combines a fullscreen retro-style clock with mood-based motivational quotes, Pomodoro focus sessions, Lock-in Mode, custom quotes, favorites, and productivity stats.

## Live Demo

https://lockin-clock.onrender.com

## GitHub Repository

https://github.com/Nikil245/lockin-clock

## Features

- Real-time fullscreen flip clock
- Smooth flip clock animation
- 12-hour and 24-hour time format toggle
- Mood-based motivational quote system
- 50+ quotes per category
- Category-based dynamic themes and accent colors
- Pomodoro timer with Focus, Short Break, and Long Break modes
- Pomodoro Start, Pause, Resume, Reset, and Skip controls
- Focus session tracking
- Daily streak system
- Favorite quotes
- Custom user quotes
- LocalStorage persistence
- Lock-in Mode for distraction-free studying
- Keyboard shortcuts for desktop users
- Mobile-responsive layout
- Special mobile Lock-in Mode layout
- Dark glassmorphism UI
- Deployed on Render
